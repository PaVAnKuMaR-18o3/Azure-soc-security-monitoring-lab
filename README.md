# Azure SOC Security Monitoring Lab

A hands-on Security Operations Center (SOC) monitoring lab built in Microsoft Azure to collect, investigate, and analyze Windows security events.

This project demonstrates practical SOC analyst activities including authentication monitoring, failed login investigation, process monitoring, account activity detection, and security event analysis using KQL.

---

## Project Overview

The objective of this lab is to simulate common SOC analyst workflows by collecting Windows security events from an Azure virtual machine and investigating them through Azure Log Analytics and Microsoft Sentinel.

The lab includes monitoring and investigation of:

- Successful authentication activity
- Failed authentication attempts
- Process creation activity
- User account creation
- Account lockout events

The project uses KQL queries to identify and investigate security events generated by a Windows virtual machine.

---

## Technologies Used

- Microsoft Azure
- Azure Virtual Machine
- Azure Monitor Agent
- Log Analytics Workspace
- Microsoft Sentinel
- KQL (Kusto Query Language)
- Azure Monitor Workbooks
- Windows Security Event Logs
